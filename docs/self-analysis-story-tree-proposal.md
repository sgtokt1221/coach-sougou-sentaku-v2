# 自己分析の木 2.0 提案メモ

## 結論

自己分析の木は、単なる「7ステップの進捗表示」ではなく、**自己分析が出願で使える材料へ変換されていく構造**として見せるのがよい。

現状の木は「どこまで完了したか」は伝わるが、「それが志望理由書・面接・小論文にどう効くのか」がまだ弱い。総合型選抜のプロダクトとしては、自己分析の価値を出願成果に直結させる見せ方の方が強い。

## コンセプト

木の各部位を、自己分析の意味構造に対応させる。

| 部位 | 意味                                         | UI上の役割               |
| ---- | -------------------------------------------- | ------------------------ |
| 根   | 原体験、価値観、譲れないこと                 | 生徒の内面の起点         |
| 幹   | 自分軸、一貫した人物像                       | 全体を貫くストーリー     |
| 枝   | 強み、弱みと成長、興味関心、将来ビジョン     | 自己分析の主要テーマ     |
| 葉   | 具体エピソード、活動実績、学び               | 根拠素材                 |
| 実   | 志望理由、自己PR、面接回答、小論文の独自視点 | 出願に使えるアウトプット |
| 光   | AP照合                                       | 志望校との一致度         |

## なぜこの方向がよいか

1. 生徒にとって、自己分析をやる意味が見えやすい。
2. 保護者や管理者にとって、進捗だけでなく出願準備度を説明しやすい。
3. 小論文、面接、出願書類の各機能と自然につながる。
4. 「CoachFor総合型選抜」らしい独自性が出る。

特に重要なのは、木の実を「完了バッジ」ではなく「出願素材」にすること。ここが変わるだけで、自己分析がアプリ内の孤立機能ではなく、全体の中核機能になる。

## 技術方針

本実装は **React + SVG + Tailwind + 既存UI部品** がよい。

Three.jsや生成画像ではなくSVGを使う理由:

- 各ノードをクリック可能にしやすい。
- AP照合線、選択状態、進捗状態をデータ連動しやすい。
- レスポンシブ対応がしやすい。
- 既存の `GrowthTree.tsx` と技術的な連続性がある。
- アクセシビリティ対応が比較的しやすい。

3D化は後回しでよい。見た目のリッチさより、まず「自己分析がどう使えるか」を伝える情報設計の方が重要。

## 画面構成案

- 中央: Story Tree SVG
- 右: 選択中の実の詳細パネル
- 上: 志望校APと全体スコア
- 下: 7ステップ進捗
- スマホ: SVGを無理に縮小せず、縦型の構造ビューに切り替える

右パネルで表示したい内容:

- AP一致度
- 根拠素材
- 使える出願場面
- 不足している観点
- 次に深める質問

## データ設計イメージ

`SelfAnalysis` を直接描画するのではなく、表示用に `StoryTreeNode` へ変換する。

```ts
type StoryTreeNode = {
  id: string;
  type: "root" | "trunk" | "branch" | "leaf" | "fruit";
  label: string;
  sourceStep?: number;
  apKeywords?: string[];
  evidenceIds?: string[];
  score?: number;
  status: "ready" | "needs-evidence" | "needs-ap" | "empty";
};
```

この変換層を挟むと、将来的に活動実績、出願書類、面接履歴とも接続しやすい。

## 段階実装

### Phase 1: 見た目と操作感

- 現在のプレビューをベースに、SVGの木と右パネルを本画面に統合する。
- 既存の `GrowthTree` は残し、切り替え可能にする。
- 果実クリックで詳細パネルを更新する。

### Phase 2: 実データ接続

- `SelfAnalysis` から根、幹、枝、実を生成する。
- 完了ステップに応じて表示密度を変える。
- 未入力部分は「空の実」や「弱い枝」として表示する。

### Phase 3: AP照合

- 志望校APキーワードと自己分析内容を照合する。
- 接続が強い枝や実を光らせる。
- 不足箇所に「根拠不足」「大学接続が薄い」などの状態を付ける。

### Phase 4: 出願素材への変換

- 志望理由書、自己PR、面接回答、小論文視点に転用できる文案を生成する。
- 書類エディタ、面接練習、小論文添削へ導線を出す。

## 個人的な判断

この方向は採用してよいと思う。

理由は、自己分析を「入力して終わり」の機能から、「出願戦略の中心」に格上げできるから。総合型選抜では、生徒の経験、価値観、AP、志望理由、面接回答が一貫していることが強い。この木は、その一貫性を視覚化する装置として相性がよい。

ただし、装飾に寄せすぎると弱くなる。重要なのは、木がきれいなことではなく、**どの経験がどの出願材料に変わるかが一目で分かること**。実装でもここを最優先にしたい。
