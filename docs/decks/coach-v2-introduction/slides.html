総合型選抜の指導現場が抱える課題

受験生・塾・大学情報、3 つの軸で構造的な負荷が発生している

受験生

・小論文 / 面接 / 書類 / 活動が同時並行で進む
・何から手をつけるべきか分からない
・添削や面接練習の機会が圧倒的に不足

塾

・全大学の AP / 募集要項を把握する負担
・添削に時間がかかり対応生徒数が限定
・面接練習は講師 1 対 1 で枠が取れない

大学情報

・募集要項が毎年変わる
・AP / 選考方式 / 日程の更新が高頻度
・情報源が散在して整合が難しい

機能② AI 模擬面接 (個人・プレゼン・口頭試問)

2

3 つのモード

個人面接 / プレゼンテーション / 口頭試問。大学別の面接傾向データを反映

マルチモーダル分析

11

想定される懸念 → Coach の回答

塾現場の典型的な不安に対する Coach の答え

Q1: AI 添削で十分な品質か？

A1: 大学別 AP 連動 + 弱点 DB の継続学習で個別最適化。最終確認は講師が行う運用が前提

Q2: 講師の仕事が無くなる？

A2: AI は 1 次添削 / 練習量確保を担当、講師は戦略指導 / メンタル支援 / 最終添削に専念

Q3: 既存指導と両立できる？

A3: 生徒の自学自習を補完する位置づけ。管理者ポータルで講師の指導記録に統合可能

未成年 × 受験データを扱う前提で多層防御を実装

OWASP Top10 対策

2026 年セキュリティ監査で Critical+High 10 件を対応完了。継続的に Medium 級も対応中

Firestore Rules

サーバーサイドルール検証 + IDトークン自動付与で API 全ルートに認可レイヤー

音声・映像・答案データは保持期間・閲覧権限・削除手段を明文化予定 (運用ガイドライン整備中)
